# マップ定義エディタ

マップ定義の3種類のJSONを、日本語フォームで編集するローカルツールです。
HTML・CSS・JavaScriptのみで動き、インストール・ビルド・外部サービスは不要です。

## 起動と基本操作

1. `MapDataEditor.html`をEdgeやChromeなどのブラウザで開きます。
2. **JSONを開く**で次の3ファイルをまとめて選択します。対応ブラウザでは**フォルダーを開く**でMapDataフォルダーを指定することもできます。
   - `MAP_OBJECT_PHYSICS_PRESET.json`
   - `MAP_OBJECT_ASSETS.json`
   - `BUILDING_FRAGMENT_DATA.json`
3. 左のタブと一覧から対象を選び、右のフォームで編集します。
4. エラーを解消し、タブごとに保存します。保存後はゲーム側でデータを読み込み直してください。

HTMLを直接開いた場合、隣のJSONを勝手に読み込むことはできません。ファイルを選択してください。
HTTPで配信している場合のみ、開始画面の**同じフォルダーから読み込む**も利用できます。
ツール自体に外部通信や自動保存はありません。HTTPでの同じフォルダー読み込みも、ボタンを押したときのみ行います。

## 保存方法

- **元ファイルへ保存**：ファイル選択APIに対応するブラウザで利用できます。書き込みの許可が必要な場合は、ブラウザの確認に従ってください。読み込み後に元ファイルが外部で変更されていた場合は、保存を止めます。
- **保存先を選んで保存**：ファイルの書き込み先が未選択の場合に表示されます。
- **JSONを書き出す**：編集結果をJSONとしてダウンロードします。元のファイルは更新されないため、必要な場所へ手動で置き換えてください。ダウンロード先や同名ファイルの番号付けはブラウザ設定に依存します。

直接保存APIはブラウザ・セキュリティ設定・起動方法によって利用できない場合があります。その場合はダウンロード書き出しを利用してください。
保存は現在のタブのファイルだけが対象です。IDの連動変更後は、変更マークのある全ファイルを保存してください。複数ファイルの保存は一括・不可分ではありません。

## 編集と検証

- 左側でファイルとデータを選択し、右側のフォームで編集します。デスクトップでは左右を個別にスクロールでき、上部の保存操作は常に表示されます。
- グループの見出しを押すと折りたためます。**項目説明**をONにすると、補足説明とJSONのキー名を表示します。
- 未保存の変更はファイル一覧とフォーム上部に表示します。下部の**検証結果**からエラー項目へ移動でき、折りたたまれた入力欄も開きます。
- 定義の追加・複製・削除、ID検索、最大60操作のUndo/Redo。
- 物理プリセット、アセット、破片のID参照を検証します。未読み込みの参照先は「確認できない」という注意に留めます。
- 読み込み済みデータで参照されている定義は削除できません。先に参照先を変更してください。
- IDを変更すると、読み込み済みの3種類のデータ内にある対応参照を同時更新します。Undoも連動して戻します。
- `MAP_MOUNTAINS_A.json`などの**配置JSONは編集・参照更新の対象外**です。アセットIDを変更した場合、配置JSON側は別途更新してください。
- マテリアルタグの候補は読み込んだアセットから収集します。マテリアルの登録状況、モデルファイルの存在、モデル内のスロット数は検証しません。
- JSONの知らない項目、選択形状では使わない項目も保持します。保存時に字下げ・改行・数値の文字列表現は整形されますが、未編集の値を削除しません。
- 保存時は読み込み済みの全データを検証し、エラーがある場合は保存・書き出しを停止します。注意だけなら保存できます。
- 不正な入れ子構造のJSONは、フォームを壊さないよう読み込みを拒否します。複数ファイルを開く場合も、すべてを読めるときだけ編集データへ反映します。
- 編集内容はメモリ内だけに保持します。ページを閉じる前に保存してください。ファイルを読み込み直すとUndo/Redo履歴はリセットされます。

ショートカット：フォーム入力中以外の`Ctrl+Z`で戻す、`Ctrl+Shift+Z`でやり直す、`Ctrl+S`で保存（入力中の値も確定して保存）。入力中の`Ctrl+Z`はブラウザ標準の入力取り消しです。

## 現在のエンジンに合わせた扱い

- 回転はJSONと同じ**ラジアン**です。自動的な度数変換は行いません。
- Boxの`size`は、現在のエンジンでは各軸の**半幅**です。
- Cylinderの`height`は**高さの半分**、Capsuleの`height`は**上下の半球を除いた円柱部分の高さ**です。
- 複数Colliderは現行FactoryとRigidBodyの扱いが一致していないため、2個以上の場合は保存エラーにしています。
- `NONE`は現行Factoryで未初期化RigidBodyが付く経路のため保存エラーです。判定なしのデータはColliderを0個にします。破壊挙動などはゲーム側で確認してください。
- 配置直後の質量、衝突対象、掴める設定、破片Transform等は、ゲーム側の生成・更新処理に従います。ツールはゲームコードを変更せず、物理・描画を再現しません。

## ファイル構成・確認方法

- `MapDataEditor.html`：画面構成
- `MapDataEditor.css`：表示とレスポンシブ対応
- `MapDataEditor.js`：フォーム・履歴・読み込み・保存
- `MapDataEditor.core.js`：JSON構造、参照操作、検証（UIから独立）
- `MapDataEditor.test.cjs`：データの往復・未知項目の保持・ID連動・検証の回帰テスト

Node.jsが利用できる開発環境では、このフォルダーで次を実行できます。

```text
node MapDataEditor.test.cjs
```

ツールの利用自体にはNode.jsは不要です。
