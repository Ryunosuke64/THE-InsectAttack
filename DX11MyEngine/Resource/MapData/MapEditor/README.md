# マップエディタ：配置試作

`MapEditor.html` をEdgeまたはChromeで開いて使います。ライブラリを同梱しているため、ビルド・サーバー起動・インターネット接続は不要です。HTMLだけを移動せず、このフォルダー全体を保管してください。

## 使い方

1. **FBXを開く**から、1個以上のFBXを選びます。画面へのドラッグ＆ドロップでも読み込めます。
2. FBXが外部画像を参照している場合は、その画像も同時に選びます。PNG / JPEG / WebP / BMPに対応し、参照ファイル名で照合します。画像がない場合も、画像を省略して形状を表示します。
3. 3D画面でモデルを左クリック、または左の一覧から選択します。
4. 赤・緑・青の矢印をドラッグしてX・Y・Z方向へ移動します。ハンドルの平面部分で2軸、中央で画面に沿って移動できます。右の位置欄から数値入力も可能です。
5. **全体を表示**、または**選択モデルを表示**で対象を画面内に収めます。

| 操作 | 動作 |
| --- | --- |
| 左クリック | モデルを選択。空白で選択解除 |
| 色付きハンドルを左ドラッグ | 選択モデルを移動 |
| 右ドラッグ | 視点を回転 |
| 中ドラッグ | 視点を平行移動 |
| ホイール | ズーム |
| F（入力欄以外） | 選択モデルを表示 |

## 今回の範囲

- FBX読み込み、複数モデル表示、選択、移動、削除、カメラ操作のみの試作です。
- 保存・配置JSONの入出力・回転・拡縮・Undo/Redo・物理・アニメーション再生は未実装です。ページを閉じると配置は失われます。
- 元のFBXや既存JSONを書き換えたり、外部へ送信したりする機能はありません。
- FBX内の形状・マテリアルをThree.jsで表示します。エンジン側の独自マテリアル、DDS/TGA画像、シェーダーは再現しません。FBXバージョンや内容によっては読み込めません。
- FBXLoaderが読み取った姿勢・大きさ・原点を保持し、配置移動を外側のグループに設定します。エンジンとの座標・単位の一致はまだ検証していません。複数ファイルは初期位置が重なる場合があります。
- 描画はカメラ・モデル・画面サイズの変化時に行います。大きなFBXの解析中は画面操作が一時的に止まることがあります。

## ファイル

- `MapEditor.html` / `MapEditor.css`：画面と表示
- `MapEditor.js`：ローカルファイル読み込み、選択・移動・カメラ操作
- `vendor/three-tools.js`：Three.js 0.180.0と必要なアドオンをまとめたオフライン用バンドル
- `vendor/three-entry.js`：バンドル生成元のエクスポート一覧
- `vendor/LICENSE-*.txt`：同梱ライブラリのライセンス

バンドルはThree.js 0.180.0をesbuild 0.25.10でIIFE形式にまとめたものです。再生成する場合は開発用の別フォルダーでこの2バージョンを導入し、`three-entry.js`のインポートを解決できる状態で次を実行します（通常の利用には不要です）。

```text
esbuild three-entry.js --bundle --minify --format=iife --global-name=MapEditorThree --target=es2020 --legal-comments=inline --outfile=three-tools.js
```
