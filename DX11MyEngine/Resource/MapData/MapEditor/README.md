# マップエディタ：配置試作

`MapEditor.html` をEdgeまたはChromeで開いて使います。ライブラリを同梱しているため、ビルド・サーバー起動・インターネット接続は不要です。HTMLだけを移動せず、このフォルダー全体を保管してください。

## 使い方

1. **FBX / JSONを開く**から、1個以上のFBXを選びます。画面へのドラッグ＆ドロップでも読み込めます。FBXの追加配置はまとめて1件のUndo対象になります。
2. FBXが外部画像を参照している場合は、その画像も同時に選びます。PNG / JPEG / WebP / BMPに対応し、参照ファイル名で照合します。画像がない場合も、画像を省略して形状を表示します。
3. 3D画面または左の一覧で左クリックして単体選択します。Ctrl＋クリックで選択追加・解除、Shift＋クリックで追加選択、3D画面の空白クリックで選択解除します。選択対象は黄色い枠と一覧の背景で表示します。
4. 上部の**移動・回転・スケール**を切り替え、赤・緑・青のハンドルで編集します。移動・回転の操作軸は**World / Local**で選べます。複数選択では選択範囲の中心に共通ギズモを置き、回転・拡縮は相対位置にも適用します。右の欄も選択グループの基準点・回転・倍率になります。
5. **全体を表示**、または**選択モデルを表示**で対象を画面内に収めます。Fは選択対象全体、一覧のダブルクリックはそのモデルへ滑らかにフォーカスします。
6. 右の位置・回転・スケールの数値を左右にドラッグして調整できます。クリックすると直接入力できます。入力中はX・Y・Zのラベルをドラッグしてください。Shiftで微調整、Escでドラッグ開始時の値に戻せます。
7. **前・横・上**で平行投影へ切り替えます。右ドラッグで平行投影のまま自由に視点を回転でき、**透視図**で通常表示へ戻せます。背景は初期状態では灰色で、上部の**背景**から変更できます。

回転欄は**度（°）**です。Three.js内部ではラジアンへ変換して適用します。ゲーム用JSONの回転単位（ラジアン）とは異なります。スケールは反転やゼロ倍率を避けるため、数値入力・ドラッグ・ハンドルともに各軸**0.001以上**です。

上部の**表示**から**マテリアル／単色／ワイヤー**を切り替えます。マテリアルは元のテクスチャとマテリアル、単色はテクスチャを外した陰影付きの面、ワイヤーは三角形の辺を表示します。配置済みモデル・参照地形・ランダム配置プレビューに適用し、グリッドやギズモは維持します。

**基本色**は単色／ワイヤーの共通色です。選択モデルの**単色表示色**では、単体・複数選択の表示色を指定できます。マテリアル表示中に対象の色を変えると単色表示へ切り替わります。**色をリセット**で対象ごとの指定を解除し、種類別の色（未設定なら基本色）へ戻します。複製は色を引き継ぎます。これらは表示専用で、ロック中の対象にも設定できます。Transform・Undo履歴・ゲーム用JSONには影響せず、JSONの再読み込みで対象ごとの色を解除します。元のテクスチャは保持し、マテリアル表示へ戻せます。

**一括で色を変更する（同じID）**をONにして色を指定すると、選択対象と**同じアセットID**の全オブジェクトへ適用します。例：Tree_01を選択して赤を指定すると、非表示・ロック中を含むTree_01すべてが赤になります。異なるIDには影響しません。複数種類を選択している場合は、その全種類へ適用します。照合はゲームのアセットIDどおり大文字・小文字を区別します。

種類別の色はこのページを開いている間保持し、新規配置・ランダム配置プレビュー・JSONの再読み込み後の同じIDにも適用します。種類別の変更時は既存の個別指定を解除して色を統一します。その後チェックをOFFにすれば、個別の色で上書きできます。チェックONの**色をリセット**は、選択した種類の設定と個別指定をまとめて解除します。種類別の色もゲーム用JSONには追加せず、ページを閉じると失われます。

ビューで**左ボタンを押してドラッグ**すると矩形選択します。対象のワールド外接枠が選択矩形に触れたものを選び、奥に隠れた対象も含みます。非表示・ロック中の対象、参照地形、未確定プレビューは除外します。通常は現在の選択を置き換え、**Shift**で追加、**Ctrl / Command**で選択状態を反転します。ドラッグ方向は自由で、**Esc**・フォーカス喪失で選択変更を取り消します。ギズモ上からのドラッグは既存のTransform操作を優先します。矩形選択自体は配置・履歴・JSONを変更しません。

| 操作 | 動作 |
| --- | --- |
| 左クリック | モデルを選択。空白で選択解除 |
| 左ドラッグ（ギズモ以外） | 矩形選択 |
| Shift＋左ドラッグ / Ctrl＋左ドラッグ | 矩形内を追加 / 選択状態を反転 |
| Esc（矩形選択中） | 選択を変更せずに取り消す |
| Ctrl＋クリック / Shift＋クリック | 選択追加・解除 / 追加選択（一覧でも可） |
| Ctrl+Z | Undo |
| Ctrl+Y / Ctrl+Shift+Z | Redo |
| Ctrl+D | 選択対象すべてを複製。複製した対象を選択し、移動モードに切り替え |
| Delete | 選択対象すべてを削除 |
| 右クリック（ドラッグしない） | 複製・削除のメニューを表示 |
| W / E / R | 移動 / 回転 / スケールに切り替え |
| 色付きハンドルを左ドラッグ | 現在のモードで選択モデルを編集 |
| 数値または軸名を左右ドラッグ | 値を増減（右：増加、左：減少） |
| Shift＋数値ドラッグ | 通常の1/10の感度で微調整 |
| Esc（数値ドラッグ中） | ドラッグ開始時の値へ戻す |
| 数値をクリック | キーボードで直接入力 |
| 1 / 2 / 3（テンキーも可） | 前（+Zから）/ 横（+Xから）/ 上（+Yから）の平行投影 |
| 4 | 透視図へ戻る |
| 右ドラッグ | 視点を回転 |
| 中ドラッグ | 視点を平行移動 |
| ホイール | ズーム |
| F（入力欄以外） | 選択モデルを表示 |
| 一覧のダブルクリック | そのモデルへ滑らかにフォーカス |

ショートカットは数値入力中には動作しません。ビュー切り替えは現在の注視点と表示範囲を引き継ぎます。上ビューでは−Z方向が画面上です。背景色も含め、編集内容はページを閉じると失われます。

## 表示・編集ロック

- 一覧の各行の**◉ / ○**で表示・非表示、**🔓 / 🔒**で編集ロックを切り替えます。上の**選択を非表示**・**すべて表示**・**選択をロック**・**すべて解除**も使えます。検索中でも「すべて」はシーン全体を対象にします。
- 非表示は描画・3D選択から除外し、選択中なら選択解除します。一覧には残り、アイコンから表示を戻せます。非表示の行の文字は灰色・取り消し線で表示します。
- ロック対象は描画を維持し、3Dビューから選択できません。一覧から参照・フォーカス・ロック解除できます。参照中の数値欄は無効になり、ギズモを付けません。
- 混在選択は共通の編集対象判定を使い、非表示・ロック対象を移動・回転・拡縮・アセットID変更・削除・複製・地面吸着・整列・等間隔配置から除外します。共通ギズモの中心・Local軸も編集可能な対象から求めます。選択数と編集可能数を上部に表示します。
- 表示・ロックはセッション内の作業設定で、Undo履歴には追加しません。既存のUndo/Redoは記録した状態を正確に復元するため、ロックや非表示にした後でも過去の操作を取り消せます。これらの設定によってRedo履歴を破棄しません。
- 非表示・ロック中も、オブジェクト本体はJSONに保存します。設定自体は保存せず、配置JSONの再読み込み後は全対象を表示・ロック解除します。

## 整列・等間隔配置

上部の**配置ツール → 整列・等間隔配置**、または右の折りたたみパネルから操作します。

- X / Y / Zのワールド軸を指定し、Transform位置の**最小・中心・最大**へ整列します。中心は編集対象の最小座標と最大座標の中間です。2個以上の編集可能な対象が必要です。
- **指定間隔**は指定軸の座標順に並べ、最小位置を基点に入力した間隔で配置します。同じ座標では現在の選択順を維持します。間隔は0以上です。
- **両端固定・均等**は3個以上を対象に両端を動かさず、中間だけを均等に配置します。間隔は自動計算します。
- バウンディングボックスの端ではなく、各モデルのTransform原点を基準にします。選択した軸の位置だけを変え、回転・スケールや他軸は維持します。Local / Worldやグリッドスナップ設定には影響されません。非表示・ロック対象を除いた範囲で計算し、1回のUndo/Redoで一括復元します。

## ランダム配置

**配置ツール → ランダム配置**で専用パネルを開きます。

「中心をマウスで移動」をONにすると、配置範囲の中心を3Dビューの移動ギズモ（ワールド座標）でドラッグできます。「配置範囲を表示」またはON中のFキーで範囲を画面に収めます。位置スナップも利用できます。再度ボタンを押すかモデルを選択するとモデル編集に戻ります。

中心・配置数・半径・幅・間隔・角度・倍率の数値欄は、左右ドラッグで増減できます。Shiftで微調整、Escでドラッグ開始時の値に戻します。クリックして直接入力する操作も維持しています。入力中でも項目名をドラッグできます。設定変更時は既存プレビューを破棄するため、変更後に「プレビュー更新」を押してください。

1. 読み込み済みの配置アセットを選び、配置数（1〜2000）を指定します。アセット定義だけでFBX未読み込みのものは候補に表示しません。
2. 円または矩形、中心XYZと半径／幅・奥行きを設定します。範囲はワールドXZ平面、中心Yは吸着OFF時の配置高さです。青緑の枠線が配置範囲を示します。
3. 最小間隔、地面吸着、Y回転の角度範囲、均一スケールの倍率範囲、シードを設定します。角度は度、スケールは0.001以上です。各ランダム化をOFFにするとY回転0・倍率1を使います。
4. **プレビュー更新**で生成結果を確認します。**プレビューを表示**で未確定分へフォーカスできます。未確定分は選択・編集・履歴・JSONの対象に含めません。
5. **確定**で通常の配置オブジェクトへ登録し、新しい内部IDで選択します。確定した一括配置は1回のUndoで取り消し、Redoで同じID・Transform・選択を復元します。

円は半径に平方根を使い面積に対して均一に分布させ、矩形も範囲内で均一に生成します。乱数は文字列シードのハッシュとMulberry32を使い、配置計算は`Math.random()`に依存しません。同じシード・設定・既存配置・地形なら同じ結果を再生成できます。確定によって既存配置が増えると最小間隔の条件も変わります。

最小間隔は**Transform原点間のXZ距離**です。新規候補同士に加え、非表示・ロック対象も含む既存配置を避けます。メッシュ同士の重なりや大きさの自動判定ではありません。空間ハッシュで近隣候補だけを比較します。

地面吸着ONでは既存の地形Raycast処理を再利用し、地面のない候補を捨てて再試行します。地形が未指定なら生成を開始しません。試行は`max(100, 配置数×50)`回、最大100000回で終了し、配置数・試行数・地面なし候補数をパネルに表示します。条件を満たせない場合は部分的な結果になり、0件なら確定できません。

生成処理は約8msごとにブラウザへ制御を返します。生成中もカメラ操作とキャンセルができ、他の編集は一時的に止めます。**キャンセル**またはパネルを閉じる操作で、プレビューと範囲ガイドを破棄します。設定変更やシーンの編集・Undo/Redo・地形変更では古いプレビューを無効にし、再生成を求めます。

シードや範囲、プレビュー、表示・ロックなどの作業状態はゲーム用JSONに追加しません。保存するのは確定済みオブジェクトの従来の4項目だけです。FBXの複雑さや確定後のオブジェクト数により、描画や選択の負荷は増えます。

## 検索・座標系・フォーカス

- 一覧上部でアセットIDを部分一致検索します。大文字・小文字を区別せず、入力ごとに一覧と「結果件数 / 全件数」を更新します。×ボタンで解除できます。
- 検索は一覧だけを絞り込みます。シーン・Transform・履歴には影響しません。検索で隠れた選択も維持するため、一括編集・削除・Fの対象には隠れた選択も含まれます。各行の内部IDで同じアセットを個別に選択できます。
- **World**はワールド軸、**Local**はオブジェクト自身の回転に沿う移動・回転です。初期値はWorldです。複数選択のLocalは最後に選んだActive対象の向きを使います。Activeは一覧とインスペクタに表示します。Shiftで選択済みの行をクリックするとActiveをその行へ切り替えられます。
- 座標系の変更は編集用のギズモだけに適用し、オブジェクトのTransformや履歴を変更しません。複数選択のプロキシ回転・倍率は切り替え時に基準を合わせ直します。数値欄の位置は常にワールド座標で、スケールは既存どおり各モデルのローカル倍率です。
- Local移動ギズモのスナップは開始位置からローカル軸に沿って指定間隔ずつ移動します。World移動は従来どおりワールドグリッドに揃えます。回転スナップも選んだ軸で動作します。
- Fは選択中の全モデルの形状のバウンディングボックスから中心・距離を計算し、約0.24秒でフォーカスします。極端な原点オフセットを持つモデルでも形状の中心を使います。現在の視線方向と投影方式は維持します。右・中ドラッグ、ホイール、タッチ操作、ビュー切り替え、選択変更・編集で補間を中断します。未選択時は何もしません。

## 地面への吸着

既存の`groundAssetTag`にはエディタ内の地形メッシュへの対応情報がなく、ゲーム側の地面も配置JSONと別の処理で生成されています。そのため、自動でタグを解決したりY=0の平面で代用したりせず、実際に読み込んだメッシュを明示的に使います。

1. 右下の**地面・地形**を開き、**参照地形FBXを開く**で地形を読み込みます。外部画像はFBXと一緒に選択できます。参照地形はFBXの姿勢・単位・原点で表示し、配置オブジェクトの一覧・履歴・JSONには含めません。クリアボタンで参照地形だけを解放できます。
2. 既存の配置モデルを使う場合は、そのモデルを選択して**選択対象を吸着先の地形にする**をONにします。必要な位置・回転・スケールへ編集してから指定できます。この分類は内部IDごとの編集用設定で、ゲーム用JSONには保存しません。分類した配置モデル自体は通常の配置データとして保存されます。
3. 配置するモデルを選び、**地面へ吸着**を押します。複数選択時も個別に高さを求め、まとめて1回のUndo/Redoで復元できます。地形に分類された選択対象自身は移動しません。

回転・スケール適用後のワールドバウンディングボックスの底面を使います。底面範囲の中央・辺・角の9点から、識別済み地形の三角形だけに下向きRaycastし、得られた最も高い接地点に底面を合わせます。地形がオブジェクトより高い場合も復帰できます。Y以外の位置・回転・スケールは変えず、グリッドスナップはこの操作には適用しません。地面が見つからない対象はそのまま残し、件数を通知します。

これはバウンディングボックスによる接地支援です。底面サンプル間の細かな突起・穴や、複雑な形状同士の厳密な接触・傾斜への姿勢合わせは扱いません。地形の判定は明示指定だけで行い、未指定の建物や自分自身には吸着しません。`groundAssetTag`に対応するFBX・Transformの自動取得は未対応です。ゲーム側の地形と一致させる場合は、同じFBXとTransformを指定してください。

配置JSONを再読み込みすると配置モデルの地形分類は解除します。参照地形FBXはセッション内に保持します。削除のUndoでは同じ内部IDの地形分類を復元でき、複製は分類を引き継ぎます。検索条件・座標系・カメラ・地形分類・参照地形はゲーム用JSONに追加しません。

## Undo / Redoとスナップ

- 上部のUndo / Redoボタンも使えます。位置・回転・スケール・アセットID、FBXの追加配置、削除、複製が対象です。選択やカメラ・背景・スナップ設定は履歴に含めません。
- 履歴は最大100操作です。ギズモ・数値ドラッグは開始から終了までを1操作にまとめ、途中のフレームは保存しません。取り消し後に新しい編集を確定するとRedo履歴を破棄します。値が変わらなかった操作やEsc取消では履歴を追加しません。
- オブジェクトの識別には、アセットIDとは別の内部IDを使います。複数の同じアセットを個別に編集でき、Undo/Redoで同じ個体と選択を復元します。
- 複製は形状・マテリアルを共有し、Transformと内部IDを独立させます。削除対象は履歴から復元できる間保持します。履歴から外れた削除個体は解放し、読み込んだFBX原本は再配置用にセッション内で保持します。
- スナップは上部2段目で設定します。位置は初期値1、回転は初期値15°、どちらも初期OFFです。間隔変更やON/OFFだけでオブジェクトは動きません。
- 位置のドラッグでは開始セル内を保持し、セル境界を越えたときにグリッドへ揃えます。つかんだ瞬間の飛びを防ぎます。直接入力は指定した値を最寄りのグリッドへ丸めます。
- 回転ギズモは開始姿勢から指定角度ずつ回転します。数値ドラッグは開始セルから移動し、直接入力は指定角度を最寄りの間隔へ丸めます。OFF時は自由編集できます。
- 複数選択の位置スナップはグループの中心にのみ適用し、各個体の相対位置を保持します。背景のグリッドは全体表示時の縮尺に合わせた表示用で、スナップ間隔は設定欄の値が基準です。

## 配置JSONの読み込み・保存

現行コードには入出力が未実装だったため、配置の往復に必要なローカル入出力を追加しています。

1. 対応するFBXと、必要なら`MAP_OBJECT_ASSETS.json`を読み込みます。定義内の`modelPath`のファイル名でFBXと対応付けます。ファイル名が重複する別モデルの自動判別には対応していません。
2. アセット定義がない場合、FBXファイル名の拡張子を除いた名前をアセットIDに使います。右の**アセットID**でも変更できます。ゲームに登録済みの正しいIDを使ってください。
3. `MAP_MOUNTAINS_A.json`のような配置JSONを開きます。FBX・画像・アセット定義・配置JSONをすべてまとめて選択することもできます。対応FBXが不足する場合は読み込みを中止し、元の配置・選択・履歴を保持します。
4. 右側の**マップ情報**で**マップ名 (mapName)**と**地面アセット (groundAssetTag)**を入力します。配置JSONの読み込み時は既存値を表示し、編集した値を同じキーで保存します。マップ名は空欄にできません。地面アセットはゲーム用のタグで、参照地形FBXの表示を自動変更する機能ではありません。マップ情報の入力はオブジェクトのUndo履歴には含めません。
5. **JSON保存…**で保存先とファイル名を指定します。File System Access APIが使える環境ではOSの保存ダイアログを開き、選択した場所へ書き込みます。キャンセルすると保存しません。毎回ダイアログを開くため、選択なしで既存ファイルを上書きすることはありません。
6. 保存先選択に非対応・制限付きの環境では、ファイル名入力ダイアログを表示し、**ダウンロード**を押して書き出します。保存フォルダーはブラウザーのダウンロード設定に従います。Webページからこのフォルダーを強制指定することはできません。APIの要件は[Chromeの公式説明](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)を参照してください。

保存名の候補は、読み込んだ配置JSONのファイル名、または未読み込みの場合はマップ名です。保存成功後は直前に指定した名前を候補にします。ファイル名とmapNameは別々に指定でき、ファイル名を変更してもmapNameは変わりません。拡張子の省略時は`.json`を補います。

配置JSONの再読み込みに成功すると、配置を置き換え、選択とUndo/Redo履歴をクリアします。FBXの追加配置やアセット定義だけの読み込みでは履歴をクリアしません。

保存する各`objects`要素は既存の`assetID`・`position`・`rotation`・`scale`だけです。Transformは数値3個の配列、回転はラジアンです。`mapName`・`groundAssetTag`など元のマップ情報は維持します。内部ID・選択・ギズモ・履歴・スナップ設定は保存しません。JSONの字下げと数値の表記は整形されます。

エディタの表示・数値欄・ランダム配置の中心はThree.jsの右手系です。ゲームのFBX読み込みはAssimpの`aiProcess_MakeLeftHanded`でZを反転するため、保存時は位置を`[x, y, -z]`、回転を`[-x, -y, z]`へ変換します。読み込み時は逆変換し、既存ゲーム用JSONをそのまま往復できます。スケールは変更しません。配置用の回転順序はゲームの`XMQuaternionRotationRollPitchYaw`と対応する`YXZ`です。FBX内部のノード・骨の回転順序は変更しません。

例：エディタで位置Zを`10`にすると、JSONには`-10`を保存し、再読み込みするとエディタ上では`10`に戻ります。参照地形も元のFBXを右手系で表示し、配置オブジェクトとの位置関係を維持します。

この修正前のエディタが保存したJSONには座標系の識別情報がなく、既存ゲーム用JSONと自動判別できません。すべての配置JSONをゲーム座標として扱い、既存ファイルの一括書き換えや旧形式の推測変換は行いません。

配置JSON未読み込みの新規セッションでは`mapName`は`NewMap`、`groundAssetTag`は空文字です。既存マップの情報を使う場合は、その配置JSONを読み込んでから編集してください。

## 今回の範囲

- FBX表示、表示切り替え・ロック、検索、単体・複数選択、移動・回転・スケール、Local / World、数値ドラッグ、地面吸着、整列・等間隔配置、シード付きランダム配置・プレビュー、複製・削除、Undo/Redo、スナップ、配置JSON入出力、カメラ操作、フォーカス、平行投影、背景色変更に対応します。
- 物理・アニメーション再生は未実装です。未保存の編集はページを閉じると失われます。
- 元のFBXを書き換えたり、外部へ送信したりする機能はありません。
- FBX内の形状・マテリアルをThree.jsで表示します。エンジン側の独自マテリアル、DDS/TGA画像、シェーダーは再現しません。FBXバージョンや内容によっては読み込めません。
- FBXLoaderが読み取った姿勢・大きさ・原点を保持し、位置・回転・スケールを外側のグループに設定します。ゲームの左手系と配置回転順序に対応するJSON変換を行います。座標変換・複合回転はDirectXMathの計算と照合していますが、ゲーム画面での比較、FBXLoaderとAssimpのモデル固有の単位・ノード処理の差は未検証です。複数ファイルは初期位置が重なる場合があります。
- グループの非等方スケールは、基準軸に沿った相対位置と各モデルのローカル倍率へ適用します。JSONに表現できない「せん断」は生成しません。
- 描画はカメラ・モデル・画面サイズの変化時に行います。大きなFBXの解析中は画面操作が一時的に止まることがあります。

## ファイル

- `MapEditor.html` / `MapEditor.css`：画面と表示
- `MapEditor.js`：ローカルファイル読み込み、選択、Transform編集、数値ドラッグ、カメラ操作、背景色変更
- `MapEditor.core.js`：コマンド履歴、スナップ計算、配置JSON検証・出力
- `MapEditor.scene.js`：地形Raycast、バウンディングボックス、カメラフォーカス計算
- `MapEditor.placement.js`：整列・等間隔配置、シード付き乱数、最小間隔付き候補生成
- `MapEditor.scatter.js`：ランダム配置パネル、分割生成、範囲ガイド、未確定プレビュー管理
- `MapEditor.appearance.js`：表示用マテリアル・オブジェクト色の管理と元マテリアルの復元
- `MapEditor.selection.js`：左クリック・矩形選択のポインター操作と選択枠の管理
- `MapEditor.export.js`：保存先選択・書き込み、ファイル名入力付きダウンロード、キャンセル・失敗処理
- `MapEditor.test.cjs`：外部依存のない履歴・JSON形式・スナップのテスト
- `MapEditor.browser.test.cjs`：任意のPlaywrightによる実FBX・ギズモ・複数選択・JSON入出力のブラウザテスト
- `MapEditor.fixtures.cjs`：テスト専用の傾斜地形FBX生成（通常起動時は未使用）
- `vendor/three-tools.js`：Three.js 0.180.0と必要なアドオンをまとめたオフライン用バンドル
- `vendor/three-entry.js`：バンドル生成元のエクスポート一覧
- `vendor/LICENSE-*.txt`：同梱ライブラリのライセンス

Node.jsがある環境で、このフォルダーから`node MapEditor.test.cjs`を実行できます。ブラウザテストは開発環境にPlaywrightとEdgeがある場合に`node MapEditor.browser.test.cjs`を実行します。別のブラウザ実行ファイルは環境変数`MAP_EDITOR_BROWSER`、スクリーンショットの保存先は`MAP_EDITOR_TEST_OUTPUT`で指定できます。通常のツール利用にNode.js・Playwrightは不要です。

表示モードは実際のWebGL描画時のマテリアルを確認します。保存先選択APIの成功・キャンセル・権限拒否・書き込み失敗は模擬ファイルハンドルで検証し、ダウンロード方式は実際のJSON出力と再読み込みまで検証します。OSの保存ダイアログ自体の自動操作は行いません。

バンドルはThree.js 0.180.0をesbuild 0.25.10でIIFE形式にまとめたものです。再生成する場合は開発用の別フォルダーでこの2バージョンを導入し、`three-entry.js`のインポートを解決できる状態で次を実行します（通常の利用には不要です）。

平行投影の追加では、同梱バンドル内に既に含まれていた`OrthographicCamera`を公開エクスポートに追加しています。生成元の`three-entry.js`にも追加済みです。

```text
esbuild three-entry.js --bundle --minify --format=iife --global-name=MapEditorThree --target=es2020 --legal-comments=inline --outfile=three-tools.js
```
